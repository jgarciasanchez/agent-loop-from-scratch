# web

Mini React/TSX chat interface for `01-minimal-loop`. Scaffolded with Vite
(`react-ts` template).

## Running it

Requires the agent server running (`npm run server` from the repo root).

```bash
npm install
npm run dev
```

Open http://localhost:5173. The API base URL defaults to
`http://localhost:3001` and can be overridden with `VITE_API_URL`.
